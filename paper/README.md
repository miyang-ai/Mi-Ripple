# Paper and figures

The accompanying manuscript is:

> Yicheng Xu, Jiayin Chen, and Muting Wang. “MIRAGE: Restoring Images
> Degraded by Iterative AI Editing.” MIYANG Technology (Shanghai) Co., Ltd.,
> 2026.

Contents:

- [`manuscript.tex`](manuscript.tex): publication manuscript;
- [`references.bib`](references.bib): cited work;
- [`figures/`](figures/): original PDF figures and rendered PNG previews used by
  GitHub.

Build from this directory with an ACM-compatible TeX installation:

```bash
latexmk -pdf manuscript.tex
```
