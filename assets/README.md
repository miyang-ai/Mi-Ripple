# Documentation assets

The comparison images in `comparison/` are the same curated assets used by the
MIYANG Lab digital-ripple tool at <https://lab.miyang.cn/ripple/>.

They are included to demonstrate the research implementation. They are not test
fixtures and are not required to run the package.
